NA Profile

A Practical Path to Better Grid Model Exchange

We are working toward a simple, shared CIM-based profile approach for North American transmission planning and operations – designed to reduce manual transformation, improve consistency across tools, and support practical interoperability.

Why this effort exists

Across North American transmission environments, model exchange still involves too much manual transformation, inconsistent interpretation across tools, and unclear profile guidance. Stakeholders told us these issues slow delivery, increase reconciliation work, and make interoperability harder than it should be.

Mission and goals

Our mission is to define and demonstrate a simple, shared North American CIM profile approach for transmission planning and operations. The goal is not to start from scratch, but to use what already exists where possible, prove value through practical demonstration, and expand based on real use cases.

The plan

Confirm the first scope – identify the initial profile/testing target.
Define priority use cases – focus on the exchanges causing the most friction.
Build the framework – governance, alignment, participation model, and test artifacts.
Demonstrate value – prepare for interoperability testing and stakeholder-visible proof.

This effort is moving forward as a staged work plan: define scope, prioritize use cases, establish governance, and demonstrate value through practical interoperability activity. Get involved

What’s in it for stakeholders

Utilities / Transmission Owners

Less manual reconciliation.

Better exchange with neighbors and vendors.

More confidence in incoming model data.

Early influence on scope and priorities.

ISOs / RTOs

Cleaner exchange expectations.

More consistent model interpretation.

Stronger coordination across organizations.

Better basis for scalable operations exchange.

Vendors / Partners

Clearer implementation target.

Less custom interpretation per customer.

Opportunity to demonstrate existing capability.

Direct input into profile and testing priorities.

Why a demonstration matters

A successful interoperability effort has to be visible, practical, and credible. Demonstration matters because it shows what existing tools can do today, helps stakeholders evaluate real capability, and turns abstract standards discussion into evidence-based progress.

See real tool capability
Learn directly from implementers
Validate priorities before scaling
