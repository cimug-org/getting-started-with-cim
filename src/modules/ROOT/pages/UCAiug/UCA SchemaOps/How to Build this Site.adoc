== How to Build this Site

=== Build the Template

If you need to update the layout template for an AsciiDoc-based site, you'll want to identify the correct template from the UCAiug repositories.

For most typical knowledge-base, informational pages:

* https://github.com/cimug-org/antora-ui-uca-kb-spec

For most profiles or UML-based artifacts:

* https://github.com/cimug-org/antora-ui-cimug-spec

For example, https://github.com/cimug-org/prof-ap-cim is built using https://github.com/cimug-org/antora-ui-cimug-spec


Once you know your template, check it out using git and make the changes you need. 

NOTE: You'll need to understand the impacts of any code changes, because all future website builds using that template will be impacted.

When you are ready to test and do some review of the new template:

[source]
gulp bundle

If this is successful, you can go on to build the actual site locally (referencing your newly built bundle).

=== Build the Site

Now, if you already know your template, or if you have built it, you'll want to review the antora.yml in the site's src directory. You need to make sure the antora.yml and nav.adoc reference the correct pages and partials. If you are starting from scratch, you can use other sites as an example.

If you are going to make edits, or add new pages, do so now. It is strongly recommended to build locally before doing a full build and publish.

A typical local build of a site looks like:

[source]
antora --extension @antora/lunr-extension .\antora-playbook.local.yml

Note the lunr-extension, which provides some additional search functionality. If you don't need or don't reference this extension, you can ignore that flag.

Once you've made the edits and reviewed the locally built html, you're ready to build using antora-playbook.yml. 

Ensure that the paths are correct. Commit to Git, and verify that GitHub is automatically building the live site. Review the live site, and repeat the process as needed.
