1. Terms and definitions

For the purposes of this document, the terms and definitions given in IEC 61968-2 and the following apply.

Refer to International Electrotechnical Vocabulary, IEC 60050, for general glossary definitions.

1.1.

energy management system
EMS

computer system comprising a software platform providing basic support services and a set of applications providing the functionality needed for the effective operation of electrical generation and transmission facilities so as to assure adequate security of energy supply at minimum cost

1.2.

distribution management system
DMS

computer system comprising a software platform providing basic support services and a set of applications providing the functionality needed for the effective operation of electrical distribution facilities so as to assure adequate security of energy supply at minimum cost

1.3.

unified modeling language
UML

formal and comprehensive descriptive language with diagramming techniques used to represent software systems, from requirements analysis, through design and implementation, to documentation

Note 1 to entry: UML has evolved from a collection of methods contributed by different practitioners, into an OMG Standard in November, 1997. The CIM relies on UML for defining the model, and automated tools generate the documentation, schemas, and other artefacts directly from the UML. A basic understanding of UML is necessary to understand the CIM.

1.4.

common information model with operations support extensions
SupportCIM

union of the base CIM in IEC61970 and additional packages defined in this document, IEC 61968-11

Note 1 to entry: The SupportCIM is intended to address most of the domain modelling needs of a DMS and back office applications; however, a specific project may require other CIM packages or extensions.

1.5.

profile

subset of SupportCIM classes, associations and attributes needed to accomplish a specific type of interface

Note 1 to entry: It may be expressed in XSD, RDF, OWL and/or other serialisations. A profile can be tested between applications. A profile is necessary in order to “use” the SupportCIM. Several profiles are defined in other parts of the IEC 61968 family of standards.

1.6.

XML schema

schema used to define the structure, content, and semantics of extensible mark-up language (XML) files

Note 1 to entry: XML schema is a W3C standard that may be used to generate standardized messages. XML schemas are generally found in files with an “xsd” extension.

1.7.

resource description framework
RDF

web (W3C) standard used to represent information models

Note 1 to entry: RDF is more powerful than XSD because it can describe a data model, not just an XML file. A subset of RDF is used to support power system model exchange.

1.8.

web ontology language
OWL

another Web (W3C) standard that includes RDF and extends it

Note 1 to entry: OWL is more powerful than RDF in supporting data types, enumerations, more details of class relationships and associations, etc.
